# Key Application Workflows

## 1. Appointment Booking Workflow
Patient → Select Service → Select Doctor → Choose Date → Load Available Time Slots → Select Slot → Enter Reason → Confirm Booking → Notification Triggered.

## 2. Doctor Consultation Workflow
Doctor → View Today's Queue → Select Patient → Review Past Medical Records → Record Chief Complaint & Examination Notes → Enter Diagnosis → Create Optical Prescription → Set Follow-up Date → Complete Consultation.

## 3. Hospital Admin Workflow
Admin → Access Operational Dashboard → Manage Doctor Rosters → Configure Department Services & Slot Schedules → Review Hospital Metrics.
